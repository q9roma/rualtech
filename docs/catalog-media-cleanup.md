# Хранение фотографий каталога

Фото очереди и аудита используют `storage/app/private/catalog-media-queue/media`.
Имя файла — SHA-256 содержимого и расширение. Назначение фото создаёт ссылку,
а не копию. Визуальное сходство не используется для удаления или объединения.

`php artisan catalog:media-cleanup` сохраняет отчёт без удаления файлов.
Отчёт: `storage/app/private/catalog-media-queue/cleanup-report.json`.
Команда также обновляет журнал первого обнаружения неиспользуемых файлов.

`php artisan catalog:media-cleanup --consolidate` переносит уникальные фото
старого аудита в общий каталог. Совпадающие по SHA-256 старые копии остаются
на 30 дней для перехода. Читатели поддерживают старый путь как резервный.

`php artisan catalog:media-cleanup --apply` удаляет только файлы, которые
не используются как минимум 30 дней наблюдений и не обновлялись 30 дней.
Назначенные фото, фото активных задач и ссылки из истории сохраняются.
Отклонённые/заменённые фото сохраняются минимум 30 дней после изменения задачи.
Повреждённые JSON-манифесты останавливают очистку. Работающий обработчик фото
блокирует очистку. Служебные JSON, сторонние медиаархивы и product-photos
эта команда не удаляет.

Очистка включена в Laravel Scheduler ежедневно в 03:30 по часовому поясу
приложения. Для выполнения должен работать `artisan schedule:run` или
`schedule:work`. Без scheduler автоматического удаления не будет.
