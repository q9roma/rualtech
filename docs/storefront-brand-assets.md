# Логотипы в обложках товаров

Общий компонент `ProductPlaceholder` используется в карточках главной и каталога, поиске и галерее товара.

Приоритет: доступное фото → проверенный логотип → иконка категории. При ошибке загрузки применяется следующий вариант. Надписи «Фото пока нет» и дублирующей подписи бренда в обложке нет.

## Оформление

- Логотипы SVG/PNG имеют прозрачный фон. Прозрачные поля вокруг белого прямоугольника не считаются прозрачным логотипом. Цветные элементы самого знака сохраняются.
- Нет белого бокса, рамки или тени под логотипом.
- Палитра содержит до четырёх заметных цветов **используемого файла**, а не произвольный фирменный цвет. Для монохромной версии палитра нейтральная. Microsoft использует четыре цвета, Hisense — бирюзовый, Pantum — серый.
- Фон — мягкое радиальное свечение снизу, растворяющееся вверх в белый. Цвета многоцветного знака распределяются вдоль нижнего края.
- `bounds` описывает видимую область изображения, `size` — оптический масштаб. `BrandLogo` исключает влияние прозрачных полей без растяжения знака. Широкие надписи получают дополнительную ширину.
- Светлые монохромные исходники показываются тёмными через `monochrome`; фон при этом нейтральный. Synology использует тёмно-серую версию.
- Без фото и логотипа: чёрная иконка категории на нейтральном сером фоне, без текста. Для неизвестной категории — общая иконка сетки.

## Добавление бренда

1. Найти достоверный исходник у производителя или его дистрибьютора. Проверить, что это нужная компания, а не одноимённая марка.
2. Сохранить файл в `public/images/partners/`. SVG не должен содержать исполняемый код, внешние зависимости или активный HTML.
3. В `resources/js/components/storefront/brand-assets.json` записать путь, источник, палитру, видимые границы и масштаб. Ключ — нормализованное название бренда. Варианты написания добавляются в `brand-identity.ts`.
4. Проверить альфа-канал **и** вид на шахматном фоне. Наличие нескольких прозрачных пикселей ещё не гарантирует отсутствие подложки внутри изображения.
5. Сверить цвета SVG в браузере. Display P3 нельзя молча интерпретировать как чёрный; использовать подтверждённый sRGB/HEX-эквивалент.
6. Сравнить масштаб, центрирование и контраст в Storybook: «Выравнивание, палитры и контраст», «Прозрачность исходников логотипов», «Расширенный справочник брендов». Проверить маленькую обложку поиска и крупную галерею.

## Покрытие на 9 ноября 2026

В локальном каталоге проверено 135 названий брендов: 129 распознаются, 2900 из 2914 товарных записей имеют соответствующий логотип. Это весь набор записей, включая неактивные товары, а не число товаров в опубликованной витрине. Источники каждого подключённого файла сохранены в JSON-справочнике.

| Название без логотипа | Причина |
| --- | --- |
| ICU inTouch | Доступный файл из шапки официального сайта не прошёл проверку прозрачности и видимого знака |
| BOXIT | Не найден достоверный прозрачный исходник |
| IOPEN | Не найден достоверный прозрачный исходник |
| TELECOM | Не подтверждён логотип именно марки кабелей; одноимённые операторы связи не подходят |
| ACD | Найденное изображение содержит белую подложку и знак ACD Systems; соответствие марке комплектующих не подтверждено |
| NONAME | Отсутствие бренда: намеренно используется иконка категории |

Нельзя заменять неподтверждённые бренды выдуманным знаком, логотипом похожей компании или просто названием в произвольном шрифте.
