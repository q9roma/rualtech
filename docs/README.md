## Как читать статусы

- **Принято** — направление или требование подтверждено владельцем проекта. Это не означает, что функция реализована.
- **Реализовано** — есть соответствующий код. Готовность production проверяется отдельно.
- **Предложение** — проект решения, который ещё нужно согласовать.
- **Открытый вопрос** — информации или решения пока недостаточно.

Продуктовые решения ведём в `product.md`, правила ассортимента и импорта — в `catalog.md`. Старые планы и отчёты сохраняют историю; датированные результаты тестов не являются результатами проверки сегодняшнего состояния проекта.

## Документация компонентов

Storybook: `npm run storybook`, адрес `http://127.0.0.1:6006`. Статическая сборка: `npm run build-storybook`.

Stories лежат рядом с компонентами в `resources/js/components`. Используются реальные компоненты shadcn/ui и стили сайта. Демонстрационные кнопки не оформляют заявки и заказы. Основной каталог использует ProductCard с обложками по уточнению владельца от 9 ноября; компактный вариант сохранён в Storybook.

## Правила обновления документации

При изменении поведения обновлять соответствующий документ в том же изменении. Отделять состояние кода, согласованные требования и предложения. Для проверки указывать дату, среду и ограничения. Не сохранять пароли, токены, реквизиты покупателей и полные коммерческие прайсы в документации репозитория.
